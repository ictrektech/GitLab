GitLab Machine Learning Operations (MLOps) est un ensemble d'outils conçus pour vous aider dans vos workflows de machine learning.

Les fonctionnalités GitLab MLOps incluent :

- Registre de modèles : gérez vos modèles de machine learning, ainsi que les métadonnées associées telles que les paramètres, les métriques de performance, les artefacts et les journaux. Pour plus d'informations, consultez [le registre de modèles](model_registry/_index.md).
- Expériences de modèles : suivez et gérez les expériences de machine learning dans GitLab. Une version expérimentale est un ensemble de candidats modèles comparables, qui sont des variations de l'entraînement d'un modèle de machine learning. Pour plus d'informations, consultez [les expériences de modèles](experiment_tracking/_index.md).

## Client Python GitLab MLOps {#gitlab-mlops-python-client}

GitLab propose un client Python pour interagir avec les fonctionnalités GitLab MLOps.

Pour plus de détails, consultez le [client Python GitLab MLOps](https://gitlab.com/gitlab-org/modelops/mlops/gitlab-mlops).
