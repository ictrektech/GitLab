Dans les versions précédentes de GitLab, le flow Developer et Agentic Chat ne pouvaient lire que du texte ; ainsi, une capture d'écran dans un rapport de bug ou un diagramme dans une discussion de conception n'atteignait jamais le modèle. Désormais, le flow Developer, y compris lorsque vous le démarrez depuis Agentic Chat, ainsi qu'Agentic Chat dans votre IDE peuvent lire les images de votre dépôt et les pièces jointes des tickets, merge requests et commentaires du même projet, et les utiliser comme contexte.

Vous ne pouvez pas charger une image directement dans votre invite. Indiquez plutôt une image existante, par son chemin de fichier dans le dépôt ou par sa référence de chargement. Pour plus de détails, consultez la documentation.
