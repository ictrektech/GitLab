L'interface GitLab Duo Agentic Chat redessinée dans VS Code et les IDE JetBrains, introduite en version bêta dans GitLab 19.3, est désormais généralement disponible et constitue la mise en page par défaut. Vous n'avez plus besoin d'activer les fonctionnalités en version bêta et en version expérimentale pour l'utiliser.

La nouvelle mise en page ne comporte pas d'onglets. Vous démarrez des conversations, consultez votre historique de discussion et sélectionnez un agent et un modèle dans la même vue.

La nouvelle mise en page est la mise en page par défaut dans :

- GitLab pour VS Code 7.2.0 et versions ultérieures
- Plugin GitLab Duo pour les IDE JetBrains 3.50.0 et versions ultérieures

Pour utiliser le flow Software Development ou afficher les flows que vous avez exécutés, passez à la mise en page classique depuis le panneau.
