Vous pouvez désormais partager une vue filtrée de l'inventaire de sécurité via un lien. Filtrez par couverture d'outil, nombre de vulnérabilités ou nom de projet, puis copiez l'URL et envoyez-la. Toute personne ouvrant le lien voit la même vue.

Auparavant, seule la recherche par nom de projet était enregistrée dans l'URL, si bien qu'un lien partagé perdait les autres filtres. Désormais, l'état complet des filtres est préservé, ce qui vous permet de mettre une vue en favori ou de la transmettre à l'équipe responsable de ces projets.
