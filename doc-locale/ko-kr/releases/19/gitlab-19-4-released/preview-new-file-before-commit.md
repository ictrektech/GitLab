새 파일 페이지에는 이제 **쓰기**와 **미리보기** 탭이 있으며, 편집 페이지가 수년간 제공해온 것과 동일한 탭 쌍입니다. 이를 통해 첫 번째 커밋이 존재하기 전에 Markdown 또는 AsciiDoc 파일이 어떻게 렌더링되는지 확인할 수 있습니다. 미리보기는 편집 내용을 따라갑니다. 편집 중에 파일을 `.txt`에서 `.md`로 이름을 변경하면 미리보기가 렌더러를 전환하고, Markdown에서 멀어지게 이름을 변경하면 라이브 미리보기가 중지됩니다. 스니펫도 Markdown 라이브 미리보기 기능을 추가했으며, 편집기의 오른쪽 클릭 메뉴에서 이용할 수 있습니다.

[skkzsh](https://gitlab.com/skkzsh)에게 이 기여를 주셔서 감사합니다!
