이제 조직 수준에서 보안 대시보드를 사용할 수 있습니다.

사용자는 조직의 모든 최상위 그룹에서 다음 데이터를 볼 수 있습니다:

- 취약성 심각도 패널
- 기간별 취약성
- 상위 10개 CWE
- 위험 점수
- 경과 시간별 취약성
