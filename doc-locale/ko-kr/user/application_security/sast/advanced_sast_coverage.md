[GitLab Advanced SAST](gitlab_advanced_sast.md)는 [지원되는 언어](gitlab_advanced_sast.md#supported-languages)로 작성된 코드에서 많은 유형의 잠재적 보안 취약성을 찾습니다.

GitLab은 각 잠재적 취약성에 일치하는 [Common Weakness Enumeration (CWE)](https://cwe.mitre.org) 식별자를 할당합니다. CWE 식별자는 보안 약점을 식별하는 업계 표준 방식이지만 알아두어야 할 사항이 있습니다:

- CWE는 트리 구조로 정렬되어 있습니다. 예를 들어 [CWE-22: Path Traversal](https://cwe.mitre.org/data/definitions/22.html)은 [CWE-23: Relative Path Traversal](https://cwe.mitre.org/data/definitions/23.html)의 상위 항목입니다. 상대 경로 순회 약점(CWE-23)을 특별히 탐지하는 스캐너는 정의상 보다 일반적인 경로 순회 범주(CWE-22)의 일부도 탐지합니다.
- 명확성을 위해 이 표는 GitLab Advanced SAST 규칙에 할당된 정확한 CWE 식별자를 식별합니다. 상위 식별자는 보고하지 않습니다.

GitLab Advanced SAST에 사용되는 규칙에 대해 자세히 알아보려면 [SAST 규칙](rules.md#gitlab-advanced-sast)을 참조하세요.
