- 사용자 지정 관리자 역할이 GitLab 17.9에서 [도입](https://gitlab.com/gitlab-org/gitlab/-/merge_requests/181346)되었으며, [기능 플래그](../../administration/feature_flags/_index.md) `custom_admin_roles`와 함께 제공됩니다. 기본적으로 사용 중지됩니다.
- 사용자 지정 관리자 역할이 GitLab 18.3에서 [일반적으로 사용 가능](https://gitlab.com/groups/gitlab-org/-/epics/15957)합니다. `custom_admin_roles` 기능 플래그가 기본적으로 사용으로 설정됩니다.
- 기능 플래그 `custom_admin_roles`은 GitLab 19.0에서 제거되었습니다.

{{< /history >}}

기본 역할에 하나 이상의 사용자 지정 권한을 추가하여 [사용자 지정 역할](_index.md)을 만들 수 있습니다.

> [!note]
> 일부 권한은 다른 권한에 따라 달라집니다. 예를 들어, `admin_vulnerability` 권한을 사용하려면 `read_vulnerability` 권한도 포함해야 합니다. 모든 종속성은 각 권한의 `Description` 열에 표시됩니다.
