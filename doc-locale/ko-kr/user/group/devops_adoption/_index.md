DevOps 채택을 통해 조직의 그룹이 어떻게 GitLab 기능을 채택하고 사용하는지 알 수 있습니다. 이 정보는 그룹 및 [인스턴스](../../../administration/analytics/devops_adoption.md)에서 사용할 수 있습니다.

그룹에 대해 DevOps 채택을 사용하려면:

- GitLab 기능 채택이 더딘 하위 그룹을 파악하여 DevOps 여정을 안내할 수 있습니다.
- 특정 기능을 채택한 하위 그룹을 찾아 다른 하위 그룹에 해당 기능을 사용하는 방법을 안내할 수 있습니다.
- GitLab으로 예상했던 투자 수익률을 얻고 있는지 확인할 수 있습니다.

## 기능 채택 {#feature-adoption}

DevOps 채택은 개발, 보안 및 운영에 대한 기능 채택을 보여줍니다.

| 범주    | 기능 |
|-------------|---------|
| 개발 | 승인<br>코드 소유자<br>이슈<br>머지 리퀘스트 |
| 보안    | DAST<br>종속성 검사<br>퍼징 테스트<br>SAST |
| 운영  | 배포<br>파이프라인<br>러너 |

기능은 그룹 또는 하위 그룹이 지난 전체 달력 월에 프로젝트에서 해당 기능을 사용했을 때 채택된 것으로 표시됩니다. 예를 들어, 그룹의 프로젝트에서 이슈를 생성한 경우 그룹이 해당 기간에 이슈를 채택한 것입니다.

![DevOps 채택 보고서의 개요 탭입니다.](img/devops_adoption_v17_8.png)

**개요** 탭은 다음을 보여줍니다:

- 채택된 기능의 총 개수입니다.
- 각 범주에서 채택된 기능입니다.
- **시간 경과에 따른 채택** 막대 차트의 월별 각 범주에서 채택된 기능의 개수입니다. 차트는 그룹에 대해 DevOps 채택을 활성화한 날짜부터의 데이터만 표시합니다.
- **하위 그룹별 채택** 테이블의 하위 그룹별 각 범주에서 채택된 기능의 개수입니다.

**Dev**, **Sec**, 및 **Ops** 탭은 하위 그룹별 개발, 보안 및 운영에서 채택된 기능을 보여줍니다.

DevOps 채택 보고서는 다음을 제외합니다:

- 휴면 프로젝트입니다. 기능을 사용하는 프로젝트의 개수는 고려하지 않습니다. 휴면 프로젝트가 많다고 해서 채택도가 낮아지지 않습니다.
- 새로운 GitLab 기능입니다. 채택은 채택된 기능의 총 개수이며, 기능의 백분율이 아닙니다.

## 데이터 처리 {#data-processing}

주간 작업이 DevOps 채택을 위한 데이터를 처리합니다. 처음 그룹에 대해 DevOps 채택에 액세스할 때까지 이 작업은 비활성화됩니다.

데이터 처리 작업은 매월 첫 날에 데이터를 업데이트합니다. 월간 업데이트가 실패하면 작업이 성공할 때까지 매일 시도합니다.

DevOps 채택 데이터는 GitLab이 그룹의 데이터를 처리하는 동안 최대 1분 정도 소요될 수 있습니다.

## 그룹에 대한 DevOps 채택 보기 {#view-devops-adoption-for-groups}

사전 요구 사항:

- 그룹에 대해 기자, 개발자, 유지보수자 또는 소유자 역할이 있어야 합니다.

DevOps 채택을 보려면:

1. 상단 표시줄에서 **검색 또는 이동**을 선택하고 그룹을 찾습니다.
1. 왼쪽 사이드바에서 **분석** > **DevOps 채택**을 선택합니다.
1. 월의 범주별로 채택된 기능을 보려면 막대 위에 마우스를 올립니다.

## DevOps 채택에 하위 그룹 추가 {#add-a-subgroup-to-devops-adoption}

사전 요구 사항:

- 그룹에 대해 기자, 개발자, 유지보수자 또는 소유자 역할이 있어야 합니다.

DevOps 채택 보고서에 하위 그룹을 추가하려면:

1. 상단 표시줄에서 **검색 또는 이동**을 선택하고 그룹을 찾습니다.
1. 왼쪽 사이드바에서 **분석** > **DevOps 채택**을 선택합니다.
1. **하위 그룹 추가 또는 제거** 드롭다운 목록에서 추가하려는 하위 그룹을 선택합니다.

## DevOps 채택에서 하위 그룹 제거 {#remove-a-subgroup-from-devops-adoption}

사전 요구 사항:

- 그룹에 대해 기자, 개발자, 유지보수자 또는 소유자 역할이 있어야 합니다.

DevOps 채택 보고서에서 하위 그룹을 제거하려면:

1. 상단 표시줄에서 **검색 또는 이동**을 선택하고 그룹을 찾습니다.
1. 왼쪽 사이드바에서 **분석** > **DevOps 채택**을 선택합니다.
1. 다음 중 하나를 선택합니다.

- **하위 그룹 추가 또는 제거** 드롭다운 목록에서 제거하려는 하위 그룹을 선택 해제합니다.
- **하위 그룹별 채택** 테이블에서 제거할 그룹의 행에서 **테이블에서 그룹 제거** ({{< icon name="remove" >}})를 선택합니다.
