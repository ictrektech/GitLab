GitLab Machine Learning Operations (MLOps)는 머신러닝 워크플로우를 지원하기 위해 설계된 도구 모음입니다.

GitLab MLOps 기능은 다음을 포함합니다:

- 모델 레지스트리: 머신러닝 모델을 관리하고 매개변수, 성능 메트릭, 아티팩트, 로그 등 관련 메타데이터를 함께 관리합니다. 자세한 내용은 [모델 레지스트리](model_registry/_index.md)를 참조하세요.
- 모델 실험: GitLab에서 머신러닝 실험을 추적하고 관리합니다. 실험은 머신러닝 모델 학습의 변형인 비교 가능한 모델 후보들의 모음입니다. 자세한 내용은 [모델 실험](experiment_tracking/_index.md)을 참조하세요.

## GitLab MLOps Python 클라이언트 {#gitlab-mlops-python-client}

GitLab은 GitLab MLOps 기능과 상호 작용하기 위한 Python 클라이언트를 제공합니다.

자세한 내용은 [GitLab MLOps Python 클라이언트](https://gitlab.com/gitlab-org/modelops/mlops/gitlab-mlops)를 참조하세요.
