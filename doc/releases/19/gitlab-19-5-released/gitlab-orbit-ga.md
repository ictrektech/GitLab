In previous versions of GitLab, your agents had to crawl repositories and stitch together API calls to understand how your work connects. Now you can use GitLab Orbit, a context graph of your software lifecycle.

GitLab Orbit is generally available on GitLab.com. It connects code, merge requests, work items, pipelines, and vulnerabilities in one graph that stays current as you ship. With GitLab Orbit, you can:

- Query the graph from GitLab Duo Agent Platform, or connect Claude Code, Codex, and other agents.
- Keep your existing permissions, so people and agents see only what they're allowed to see.
- Map every project, owner, and pipeline a vulnerability affects.

To start a 30-day trial, contact your account team.
