In previous versions of GitLab, your AI agents needed a separate MCP server connection to query GitLab Orbit.
Now you can add the [Orbit toolset](../../../user/model_context_protocol/mcp_server.md#select-tool-groups-toolsets) to the GitLab MCP server, so your agents get Orbit context from the connection they already use.
